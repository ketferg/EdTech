## 📖 Acerca del Proyecto

**EdTech - Tecnología Educativa S.R.L.** es una solución integral diseñada para modernizar y digitalizar el flujo de solicitudes académicas universitarias (UPDS.NET), eliminando el uso de papel, reduciendo tiempos de espera y optimizando la comunicación entre estudiantes, docentes y administración.

### Características Principales

- **Presentación Ejecutiva e Interactiva:** Resumen financiero, métricas de impacto ambiental y propuesta de valor.
- **Simulador Interactivo de Solicitudes:** Prototipo funcional para el seguimiento en tiempo real de trámites y solicitudes universitarias.
- **Gráficos Dinámicos:** Métricas clave implementadas con [Chart.js](https://www.chartjs.org/).
- **Diseño Moderno & Responsivo:** Interfaz adaptada a dispositivos móviles y de escritorio.
